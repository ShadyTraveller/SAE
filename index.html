How I work

Two hats, one thread: direction sets the bar; code proves it. AI is a material — like type or motion — not a substitute for judgment.

  1. Frame Audience, tone, and constraints — so the product has a point of view before the first component ships.
  2. Prototype Fast loops with real data and models. I iterate on prompts, UX, and failure states in parallel.
  3. Ship Clean interfaces, readable code, and room to grow — whether it stays a side project or scales.
